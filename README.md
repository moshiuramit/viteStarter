# viteStarter

**A simple starter kit to jump-start your HTML / JS project with Vite**

## 🚀 What is this

This repository provides a minimal scaffold for beginning a frontend project using **Vite**, with basic setup files so you can start coding quickly. It includes templates for HTML, CSS, and JavaScript, pre-configured to work out of the box.

---

## 📂 Project Structure



- **index.html** → Entry point of the app.  
- **src/main.js** → Application’s JavaScript entry (wired with Vite).  
- **src/counter.js** → Example JS module (demonstrates modular structure).  
- **style.css** → Basic styling for demonstration.  
- **vite.config.ts** → Default Vite configuration — already set up for fast dev mode and build.

---

## 🛠 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/moshiuramit/viteStarter.git
cd viteStarter


2. Install dependencies
npm install

3. Start the dev server
npm run dev


By default, your app will be served at:
👉 http://localhost:5173

4. Build for production
npm run build

5. Preview the production build
npm run preview
